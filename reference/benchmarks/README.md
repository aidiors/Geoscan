# Контрольные входы

- `coverage-v6-inputs.json` содержит геометрию и параметры свободного покрытия.
- `customer-coverage-geometry-input.json` содержит исходные условия проверки
  съёмочных проходов в вогнутой области.

Фабрики сценариев находятся в `backend/scenarios`, команды запусков в
[инструкции бенчмарков](../../docs/benchmarks.md).
Результаты новых запусков сохраняются в игнорируемом `work/`.
