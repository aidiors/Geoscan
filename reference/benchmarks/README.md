# Данные для продолжения экспериментов

- `production-portfolio-progress-2026-10-18.json` — текущая прерванная серия:
  11 из 45 расчётов восьми реальных полигонов, хеши исходников, синтетический
  парк и площадка. Не финальная приёмка; [порядок продолжения](../../docs/production-handoff-2026-10-18.md).
- `coverage-v6-inputs.json` — шесть замороженных геометрий, камера 1 с,
  профиль 60/75. Включены площадки, ресурс и локальная проекция.
- `coverage-v6-summary.json` — исторические 456 измерений двух камер и
  итоги их воспроизведения. Это стендовый baseline до подключения в приложение.
- `pipeline-acceptance.json` — 12 настоящих HTTP-планов на шести задачах,
  24 экспорта, результаты аудита и хеши всех рабочих Python-модулей.
- `service-validation-2026-10-18.json` — исправления часов камеры и боковых
  соседей, сравнение назначения, 18 масштабных планов, три повтора дедлайна,
  физический OR-Tools, приёмка и проверка живого контейнера. Содержит хеши
  исходников, к которым относятся измерения; commit-base отмечен отдельно
  от неопубликованных изменений рабочего дерева.

Новые исходные наборы генерирует `backend/scenarios/freeform.py`. Для продолжения
не нужны локальные `docs/benchmark-results/`, `outputs/` и файлы прежнего чата.
Они содержат большие промежуточные серии, а не зависимости приложения.

[Передача разработки](../../docs/session-handoff.md) содержит команды и
ограничения. [Бенчмарки](../../docs/benchmarks.md) описывают протоколы.
Проценты v6 нельзя выдавать за улучшение текущего HTTP без повторного сравнения:
у приложения более сильное исходное покрытие и реальная проверка экспортов.
