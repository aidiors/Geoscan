Точный решатель используется как эталон для небольших задач. На более крупных
сценариях применяются эвристическое распределение и локальное улучшение. Это
позволяет проверять качество результата без заявления о глобальном оптимуме всей
геометрической задачи.

## Как воспроизвести

Из каталога `backend/`:

```powershell
uv sync --locked
uv run ruff format --check .
uv run ruff check .
uv run ty check src tests benchmarks
uv run pytest -q
uv run python -m benchmarks.compare_optimizers
uv run python -m benchmarks.run_coverage_experiments
```

Проверка интерфейса выполняется из корня проекта:

```powershell
npm ci
npm run typecheck
npm run lint
npm test -- --run
npm run test:e2e
```

## Ограничения интерпретации

- Синтетические сценарии подтверждают поведение программы, но не заменяют
  полётные испытания.
- Время расчёта зависит от процессора и фоновой нагрузки; для демонстрации его
  нужно повторить на машине показа.
- Полное покрытие в проверенном сценарии не доказывает глобальную оптимальность
  маршрута.
- Совместимость экспортов подтверждена структурной проверкой. Импорт в конкретные
  версии Geoscan Planner, QGroundControl и Mission Planner остаётся отдельной
  интеграционной проверкой.
